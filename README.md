# HUSTOM-1 NIGHTFALCON — 24HR TBCC UAV

Tanzania's first hybrid rocket-turbofan long-endurance UAV. 24hr endurance, 20,400km range, triple-engine FFSC + turbofan, methane fuel. Built in Zanzibar.

## What is this?
- 12hr / 18hr / 24hr modular tanks
- Range 10,200 - 20,400 km @ 850 km/h
- Propulsion: methane turbofan + FFSC rocket
- Cost <$0.5M vs $16M MQ-9
